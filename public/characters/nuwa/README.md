# 女娲游戏模型

- `nuwa.glb`：根据用户提供的女娲四视图，以程序建模重新设计的 Q 版 3D 原型。不是图片转三维扫描，也不是原画的精确复刻。
- `directions.png`：原有四方向参考素材；GLB 加载失败时保留既有 2D 回退。
- 建模源文件：`scripts/build-nuwa-glb.mjs`。在游戏仓库执行 `npm run build:nuwa` 可重新生成模型，无需 Blender、外部服务或账号。
- glTF 2.0 二进制，14 个材质网格、41,952 个三角形，约 758 KiB；没有外部纹理或远程资源。
- Y 轴朝上，正面朝 +Z，脚底为原点，高 1.2 游戏单位，横向占地小于 1 格。
- 真实三维头发、五官、玉饰、衣袖、裙摆和飘带，PBR 材质。没有骨骼、蒙皮和动画片段，适用于当前平移与四方向转身逻辑。
- 角色身份仍是选手 ID `0`（女娲），仅供泡泡堂使用；没有更改 common 中的原始头像或其他游戏。
- 预览：`?preview=nuwa`，包含模型旋转展台和使用同一模型的棋盘试演，不读写正式比赛存档。

进一步精修可以保留相同坐标和尺寸约定，直接替换 GLB；如添加骨骼动画，需要另外接入动画播放器。
