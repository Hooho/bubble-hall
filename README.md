# 泡泡大作战

纯浏览器单机游戏，TypeScript + Three.js，无服务端、无 AI API、无需登录。

## 开发与验证

- 克隆时初始化依赖：`git submodule update --init --recursive`。`vendor/game-common` 固定公共选手资源版本。
- 安装依赖：npm ci
- 本地开发：npm run dev -- --host 127.0.0.1 --port 5174
- 类型检查与生产构建：npm run build
- 规则回归测试：npm test

## 已实现

- 选手 ID、姓名和原始头像由 `vendor/game-common/players/` 统一提供。`src/roster.ts` 仅维护泡泡堂专属性格、智力和配色；女娲战场图集仍属于本游戏。
- 开发和构建前自动运行 `prepare:players`，将公共头像复制到忽略版本管理的 `public/shared-players/`。需要手动刷新资源时运行 `npm run prepare:players`。构建后静态资源完整保留，运行不依赖 common 仓库位置或网络。
- 旧 `public/avatars/` 副本暂保留用于迁移核对，运行已不引用；公共头像后续只在 common 中维护。

- 女娲（选手 0）默认使用 `public/characters/nuwa/nuwa.glb`：根据四视图程序重建的 Q 版真 3D 原型，约 758 KiB、14 个材质网格，不含骨骼或动画。移动时旋转模型，脚底对齐格子；加载失败保留原图集回退。其他选手和 common 原始头像不变。
- 设置 → 选手图鉴 → 女娲战场试演，或打开 `/?preview=nuwa`。包含可旋转、缩放的 GLB 展台与真实棋盘试演，可下载模型、切换朝向、启动电脑对战，不读写正式存档。
- 模型生成源文件为 `scripts/build-nuwa-glb.mjs`，手动执行 `npm run build:nuwa` 重建，无需外部 3D 服务。`npm test` 同时验证 GLB 可解析、三维体积、占格尺寸和四方向转身。

- 五张地图、63 名电脑选手、三类性格和五档个体能力，四档整体难度。
- 单次比赛、64 人冠军赛：四人一组，前两名晋级，64→32→16→8→四人总决赛；晋级线和决赛名次同分加赛。旧赛制存档保留原规则完成。
- 单人试玩：完整战斗、掉落与局内计分机制，2 分钟或淘汰结束；不结算长期积分、奖励或战绩，也不覆盖正式比赛存档。
- 大厅玩法一览：战场元素、单技能槽操作、局内/长期积分、赛制与全部 10 种道具；图鉴复用同一份内容。
- 120 秒比赛，最后存活者提前胜出，否则比较存活者得分；全部淘汰或最高分并列为平局。
- 炸箱 +10、有效命中 +100、拾取金币 +5；自伤和无敌受击不加分。
- 十种道具：金币、炸弹容量、范围、移动速度、护盾、额外生命，以及无敌、超级炸弹、疾跑、连发四种主动技能。
- 长期积分、难度倍率、晋级奖励、冠亚季军与八强荣誉、历史赛果。
- 奖励币衣橱：完赛获得，兑换配色，不影响战力；与场内金币独立。
- 桌面键鼠、手机竖屏下方双手操作、横屏两侧操作；设置可强制触控。
- 画质、声音、减少动态效果、道具图鉴和选手图鉴。
- 自动存档、暂停续赛、JSON 文件与压缩存档码导入导出、上一版备份及历史恢复点、多标签页冲突保护。

冠军赛的非玩家小组采用统计模拟，不运行多个隐藏 3D 战场。积分榜为本浏览器离线榜，不是联网排名。触控已经过桌面浏览器多尺寸检查，仍需真机验证触感与性能。

## 公共逻辑与德州扑克的边界

选手身份、原始头像和通用存档核心来自固定 commit 的 `vendor/game-common`。泡泡堂的性格、能力、赛事、计分与数据校验单独维护；不复用德扑 UI。

`src/shared/save-store.ts` 仅是泡泡堂命名空间适配器，底层使用从德扑提取的公共存档机制：

- load / parse：兼容原有 `bubble-club:save:v1` 存储键和旧 JSON 信封，校验内容及本游戏结构。
- write：要求预期修订号，复用公共 Web Locks 防覆盖机制；保留上一份备份和最多五份独立历史恢复点。
- backup / recover：读取有效备份；损坏恢复保留原始文本，不覆盖健康的新版本。
- transfer：文件与字符串含同样的完整进度，使用 `BUBBLE-SAVE-V1.G.`（gzip）或 `.P.`（无压缩）存档码；前缀和游戏标识阻止两款游戏混用。导入及解压都限制 5 MB。

设置中的四个入口支持文件或存档码。导入先校验并预览积分、未完成比赛，再由玩家确认替换；解析失败不写入，确认前的进度保留备份。手机使用底部面板、纵向按钮，桌面使用居中窗口；复制权限不可用时提供选中文本手动复制。

不支持 Web Locks 的旧浏览器仍进行修订号检查，但不保证跨标签页写入原子互斥，请只开一个游戏标签页。存档不是防作弊系统；校验和用于发现损坏，不是数字签名。

比赛运行中每两秒保存；暂停及切换到后台时保存。恢复后先暂停。单次对战和冠军之路分别保存未完成比赛；入口下方显示“继续上次比赛”。旧版单存档会自动归入对应模式。开始新单局会询问是否替换。

大厅仅提供两个比赛入口，积分榜与设置在顶部；选手图鉴位于设置中，63 张原始 WebP 头像通过 common 打包到 `public/shared-players/`，不依赖另一个游戏的服务。历史战绩页面已移除，既有历史数据仍保留在存档中。

测试涵盖技能、计分、金币、存活判胜、AI 目标、赛事晋级与决赛、存档冲突与损坏恢复、结算幂等和外观兑换。
