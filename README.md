# 泡泡大作战

纯浏览器单机游戏，TypeScript + Three.js，无服务端、无 AI API、无需登录。

## 开发与验证

- 安装依赖：npm ci
- 本地开发：npm run dev -- --host 127.0.0.1 --port 5174
- 类型检查与生产构建：npm run build
- 规则回归测试：npm test

## 已实现

- 五张地图、63 名电脑选手、三类性格和五档个体能力，四档整体难度。
- 单次比赛、64 人冠军赛、同分加赛、季军赛、决赛三局两胜。
- 180 秒比赛，最后存活者提前胜出，否则比较存活者得分；全部淘汰或最高分并列为平局。
- 炸箱 +10、有效命中 +100、拾取金币 +5；自伤和无敌受击不加分。
- 十种道具：金币、炸弹容量、范围、移动速度、护盾、额外生命，以及无敌、超级炸弹、疾跑、连发四种主动技能。
- 长期积分、难度倍率、晋级奖励、冠亚季军与八强荣誉、历史赛果。
- 奖励币衣橱：完赛获得，兑换配色，不影响战力；与场内金币独立。
- 桌面键鼠、手机竖屏下方双手操作、横屏两侧操作；设置可强制触控。
- 画质、声音、减少动态效果、道具图鉴和选手图鉴。
- 自动存档、暂停续赛、JSON 导入导出、上一版备份恢复、多标签页冲突保护。

冠军赛的非玩家小组采用统计模拟，不运行多个隐藏 3D 战场。积分榜为本浏览器离线榜，不是联网排名。触控已经过桌面浏览器多尺寸检查，仍需真机验证触感与性能。

## 公共逻辑与德州扑克的边界

选手身份 ID/姓名快照来自同级 DEZHOU 项目；泡泡堂的性格与能力单独定义。未修改德州项目，也未复用它的 UI。

src/shared/save-store.ts 是无游戏与 UI 依赖的通用存档模块，参考德州的版本、校验、修订和备份机制，当前仅泡泡堂接入。其他游戏可传入自己的存储键与数据校验器复用：

- load / parse：校验版本、内容校验和、数据结构和文件大小。
- write：要求预期修订号；支持 Web Locks 的浏览器中串行写入，避免两个标签页相互覆盖。
- backup：读取上一份有效存档。
- recover：仅恢复损坏存档，原始内容保留在 damaged 键；不强行覆盖健康的新版本。

不支持 Web Locks 的旧浏览器仍进行修订号检查，但不保证跨标签页写入原子互斥，请只开一个游戏标签页。存档不是防作弊系统；校验和用于发现损坏，不是数字签名。

比赛运行中每两秒保存；暂停及切换到后台时保存。恢复后先暂停。单次对战和冠军之路分别保存未完成比赛；入口下方显示“继续上次比赛”。旧版单存档会自动归入对应模式。开始新单局会询问是否替换。

大厅仅提供两个比赛入口，积分榜与设置在顶部；选手图鉴位于设置中，头像复用 DEZHOU 的 63 张 WebP 素材并打包在本项目 public/avatars 内，不依赖另一个项目的服务。历史战绩页面已移除，既有历史数据仍保留在存档中。

测试涵盖技能、计分、金币、存活判胜、AI 目标、赛事晋级与决赛、存档冲突与损坏恢复、结算幂等和外观兑换。
